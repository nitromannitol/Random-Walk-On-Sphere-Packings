# Provenance: `BouRabeeGwynne/Upstream/BrownianMotion/`

The 17 Lean files in this directory were vendored by Leonardo Bonanno (leobon12) from
[RemyDegenne/brownian-motion](https://github.com/RemyDegenne/brownian-motion) at commit
`314f04a34ff75e18fd383917ae7fe7d77beb1b6f`, under the Apache License 2.0 (see [`LICENSE`](LICENSE)).
Their copyright and author lines, where the upstream files have them, are kept.  The adaptations,
as stated in each file, are local import paths and, in some files, recorded compatibility proof
terms.

`BouRabeeGwynne/DyadicExitApprox.lean` keeps a section of
`BrownianMotion/StochasticIntegral/ApproxSeq.lean` (Kexing Ying) from the same commit, with its
copyright and author lines.

These files were copied into this repository from leobon12's formalization (commit `cf73d6e`)
with a header naming the source; this file and `LICENSE` were added here, for the pointers in
those files.
